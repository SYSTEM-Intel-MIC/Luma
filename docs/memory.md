# Memory System

## Types

- **User Memory** — Explicitly stored by user
- **AI Suggest** — AI suggests remembering patterns
- **Automatic** — Auto-capture (opt-in)

## Storage

SQLite with keyword search. Future: vector embeddings.

## Context Injection

Relevant memories are injected into the system prompt before each agent run.

## Management

Users can:
- View all memories
- Search memories
- Add/edit/delete memories
- Enable/disable individual memories
- Clear all memories
- Toggle memory system on/off
